MODEL-GL Release Controller

Owner-operated, non-commercial software-development infrastructure.

Project overview

MODEL-GL Release Controller is a private release-engineering utility used by its owner to deploy and verify Google Apps Script automation and the related Google Sheets control data.

This public site documents the OAuth integration and privacy practices only. It does not expose private source code, credentials, model rules, market data, or user secrets.

What the software does

  • Authenticates the owner through Google OAuth.
  • Manages and verifies Google Apps Script project deployments.
  • Checks release state before and after deployment.
  • Works with owner-controlled Google Sheets used by the automation.
  • Keeps OAuth credentials in protected local or repository-secret storage.

Release architecture

Owner approval → GitHub release workflow → Google OAuth → Apps Script deployment verification → Google Sheets control state.

OAuth access is limited to the Google services required for these owner-requested development and release operations.

Security

  • No OAuth refresh token or client secret is published on this site.
  • No Google user data is sold or used for advertising.
  • Access can be revoked by the owner through Google Account security settings.
  • The project is non-commercial and does not provide a public trading or financial service.

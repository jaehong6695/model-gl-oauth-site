Privacy Policy

MODEL-GL Release Controller is an owner-operated automation tool. Google OAuth is used only for release management, verification, and spreadsheet-backed automation.

Google user data

The application may access Google Apps Script project and deployment information and Google Sheets data required by the owner's automation. Access is used only for requested deployment, verification, and automation operations.

Credential storage

OAuth credentials are stored only in protected local storage or encrypted repository secrets controlled by the owner. Secret values are not published on this website.

Sharing and sale

Google user data is not sold or used for advertising. Data is not shared except with service infrastructure required to perform the owner's requested automation.

Revocation

The owner may revoke Google OAuth access at any time through Google Account security settings.
